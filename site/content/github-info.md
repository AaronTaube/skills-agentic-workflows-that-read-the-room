## Awesome Copilot community resources

The Awesome GitHub Copilot site (awesome-copilot.github.com) organizes community contributions into **Agents**, **Instructions**, **Skills**, **Plugins**, **Canvas Extensions**, and a **Learning Hub** rather than a single "workflows" section. The Agents section alone lists 221+ specialized custom agents contributors have built for specific technologies and workflows (e.g., a ".NET Self Learning Architect" agent for complex .NET delivery).
Source: <https://awesome-copilot.github.com/> and <https://awesome-copilot.github.com/agents/>
